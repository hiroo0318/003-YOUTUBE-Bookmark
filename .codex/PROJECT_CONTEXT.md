# PROJECT_CONTEXT — 채널담 (가족용 YouTube 북마크 서비스)

최종 갱신: 2026-10-09
상태: 구현 1차(웹 푸시 제외) 코드 작성·빌드 통과(web/) / DB 마이그레이션 미적용 / 다음: 마이그레이션 적용 → .env.local 입력 → 로컬 실행 검증 → 웹 푸시

## 목적과 문제

가족이 YouTube 앱이나 사이트의 일반 탐색 화면에 들어가지 않고, 별도의 가족용 페이지에서 원하는 영상을 검색하고 부모가 승인한 채널의 영상을 시청할 수 있게 한다. 이 프로젝트에서 북마크는 영상별 저장이 아니라 승인된 채널 목록을 뜻한다. 특히 중학교 1학년 자녀가 YouTube 홈과 쇼츠의 연속 탐색 목록에 노출되는 상황을 줄이고 싶다. 영상 재생 종료 후 플레이어 안에 관련 영상이 표시되는 점은 허용한다. 이 서비스만으로 부적절한 콘텐츠 접근을 완전히 차단할 수 있다고 가정하지 않는다.

## 필요한 산출물

1. 가족별 사용자 여정 및 화면 흐름: Google 로그인 → 가족 계정 확인 → (아이) 연결된 프로필로 진입 → 검색 탭 또는 승인 채널 영상 탭 → 승인 상태 확인 → 바로 재생 또는 채널 추가 요청·부모 승인 → 승인 채널 목록 관리.
2. 핵심 요구사항과 권한 표: 최초 부모 계정, 가족 계정 추가·권한 변경, 아이별 프로필, 검색·재생·채널 승인 요청·승인 채널 목록·알림·설정 범위.
3. YouTube 연동 가능성 검토: 검색, 임베드 재생, 구독 목록, 계정 동의 및 실패 상황.
4. 단계별 범위와 검증 시나리오: 첫 버전과 후속 기능을 구분한다.

산출물 1~4는 `docs/02_service-spec.md`(v0.1 초안)에 정리되어 있다. 정책 검토는 `docs/01_youtube-policy-review.md`.

## 완료 기준

- 최초 부모 계정 등록, 가족 계정 추가와 부모/아이 권한 부여, 아이 로그인 후 연결된 프로필 진입부터 전체 검색·채널 추가 요청·재생·승인 채널 영상 목록까지의 흐름과 예외 상황이 정리되어 있다.
- 기본 크리에이터 승인 모드와 부모의 승인 모드 해제 시 동작, 승인 요청·부모 알림·승인 대기·결과 확인, 부모/아이별 계정·프로필·승인 설정 권한이 명시되어 있다.
- 검색·재생·구독 연동의 가능 조건과 제약이 공식 근거로 확인되어 있다. 특히 부모 승인 관문의 YouTube 정책 적합성이 확인되어 있다(2026-10-09 내부 검토 완료·공식 확인 없음, A안 채택).
- 개발팀이 구현 범위와 미결정 사항을 구분할 수 있다.

## 현재 범위

- 별도 모바일 우선 웹 페이지에서 Supabase Auth의 Google 로그인으로 사용자를 확인한다. 서비스 화면은 검색 결과·승인 채널 영상 목록·선택한 영상 재생 중심으로 구성하고 YouTube 홈 피드나 쇼츠 연속 탐색 목록은 제공하지 않는다.
- 최초 서비스 소유자는 사용자의 Google 계정을 부모 권한으로 등록한다. 이후 부모가 가족 계정을 추가하고 각 계정에 부모 또는 아이 권한을 부여·변경한다. 등록되지 않은 Google 계정은 로그인에 성공해도 가족 서비스 데이터에 접근할 수 없다.
- 아이 계정 1개에 아이 프로필 1개를 연결한다. 아이 권한 계정으로 로그인하면 연결된 프로필로 바로 들어간다. 승인 채널 목록, 채널 추가 요청, 거절 목록은 프로필별로 구분한다.
- 아이 화면의 기본 탭은 `검색`과 `승인 채널 영상`이다. 검색 탭에서는 검색어를 모두 입력한 뒤 검색 버튼을 눌러 YouTube 전체 검색 결과를 본다. 입력 중 자동 검색은 하지 않는다. 결과 노출과 영상 시청 권한은 분리한다.
- 승인 채널 영상 탭에는 해당 아이 프로필에 승인된 YouTube 채널의 영상 목록을 보여준다. 신규 영상도 승인된 채널이면 목록에 포함한다. 정렬·표시 개수·갱신 주기는 후속 상세 기획에서 정한다.
- 기본값은 크리에이터 승인 모드다. 여기서 크리에이터는 YouTube 채널 단위로 정의한다. 재생은 승인 채널 영상에만 제공한다. 미승인 채널 영상은 검색 결과에 보이지만 재생 버튼 없이 "채널 추가 요청" 카드로 표시하고, 아이가 요청하면 부모에게 채널 추가 요청을 보낸다. 아이 화면에는 "부모님이 고른 채널만 재생되며 YouTube 제한이 아닌 가족 설정"이라는 안내를 상시 표시한다. 부모가 해당 채널을 승인하면 그 채널의 현재·향후 영상은 별도 승인 없이 볼 수 있다.
- 부모는 크리에이터 승인 모드를 해제할 수 있다. 해제 상태에서는 전체 검색 결과의 재생 가능한 영상을 별도 승인 없이 페이지 안에서 시청할 수 있다. 설정 변경은 부모에게만 허용한다.
- 아이가 미승인 채널 영상 카드에서 채널 추가를 요청하면 부모 계정의 서비스 내 승인 대기함에 쌓인다. 부모는 로그인 후 요청 영상과 채널, 요청한 아이 프로필을 확인하고 채널 단위로 승인 또는 거절한다. 아이는 대기·승인·거절 상태를 볼 수 있다.
- 북마크는 부모가 승인한 채널 목록을 뜻한다. 영상 하나를 별도로 저장·삭제하는 북마크 기능은 만들지 않는다. 부모가 채널 승인을 취소하면 해당 아이 프로필의 승인 채널 영상 목록에서 그 채널 영상이 빠진다.
- 승인 채널 목록은 서비스 내부에서 아이 프로필별로 관리한다. 부모 승인 시 아이의 실제 YouTube 계정에 자동 구독을 추가하지 않는다. 기존 YouTube 계정의 구독 목록을 읽어오는 기능은 별개의 조건부 후속 범위로 남긴다.

## 제외 또는 보류

- YouTube 앱과 동일한 홈 피드·추천 피드·쇼츠 연속 탐색 목록을 재현하지 않는다. 검색 결과에 개별 쇼츠 영상이 포함될 수 있는지 여부는 전체 검색 정책과 별도로 검토한다.
- 영상 다운로드, 광고 제거, 플레이어 기능·링크 가리기, YouTube 이용 제한 우회는 범위에서 제외한다.
- YouTube 계정의 구독 정보 연결과 YouTube 구독 변경은 최초 버전의 필수 범위로 확정하지 않는다. 서비스 Google 로그인은 기본 범위에 포함한다.
- 기술 스택(Supabase 외 프론트·배포처), 상세 화면 디자인은 아직 결정하지 않았다. 바이브코딩 시작 때 정한다. Living Plan 하네스는 지금 적용하지 않는다.

## 확인된 사항

- 사용자 요청: 가족 계정으로 로그인, 아이 프로필 선택, 전체 검색 결과 노출, 페이지 내 시청, 프로필별 승인 채널 목록. 아이 화면은 검색 탭과 승인 채널 영상 탭으로 나눈다.
- 사용자 확정: 검색은 전체 검색어를 입력한 뒤 실행한다. 부모 승인 채널은 서비스 내부 목록으로 관리해도 충분하며, 아이의 실제 YouTube 구독에 자동 반영할 필요는 없다. 별도 영상 북마크는 없고 승인 채널 영상 탭이 북마크 경험을 담당한다. YouTube 계정의 기존 구독 목록 조회는 별도 후속 가능성으로 남긴다.
- 사용자 확정: 본인 Google 계정을 최초 부모로 등록하고, 이후 부모가 가족 계정을 추가해 부모/아이 권한을 지정한다. 아이 권한 계정은 연결된 아이 프로필 1개로 사용한다(2026-10-09 1:1 연결 확정). 서비스 로그인에는 Supabase Google OAuth를 사용할 계획이다.
- 사용자 요청: 승인 요청을 부모가 놓치지 않도록 메일·앱 푸시 등을 무료 운영 기준으로 비교한다.
- 사용자 확정: 목적은 자체 페이지에서 YouTube 홈·쇼츠 목록 노출을 피하는 것이다. 영상 종료 후 플레이어 안의 관련 영상 표시는 허용한다.
- 사용자 확정(2026-10-09): 정책 검토 결과에 따라 A안 채택 — 재생은 승인 채널 영상만, 미승인 결과는 채널 추가 요청 카드. Compliance Audit은 신청하지 않고 가족 전용으로 운영한다.
- 사용자 확정(2026-10-09): 계정은 이메일 사전 등록, 아이 계정 1개 = 프로필 1개, 승인은 프로필별, 거절 채널은 부모 해제 전까지 재요청 불가, 알림은 PWA 웹 푸시만(부모: 요청 도착, 아이: 승인·거절 결과), 아이·부모 모두 iOS와 Android 사용, 개별 쇼츠 허용, 승인 채널 영상 탭은 최신순 통합 + 채널 필터.
- 사용자 확정: 기본값은 크리에이터 단위 승인이다. 미승인 영상에서 승인 요청을 만들고 부모가 크리에이터를 승인하면 이후 그 크리에이터의 영상은 계속 볼 수 있다. 부모는 승인 모드를 꺼서 전체 검색 → 바로 시청을 허용할 수 있다. 단, 이 승인 관문의 YouTube API 정책 적합성은 아직 확인이 필요하다.
- YouTube Data API의 검색은 영상 결과와 임베드 가능 영상 필터를 지원한다. `safeSearch=strict`는 제한된 콘텐츠를 제외하려고 시도하는 검색 옵션이며 자녀 안전을 보장하는 승인 체계가 아니다.
- YouTube IFrame 플레이어로 페이지 내 재생할 수 있다. `rel=0` 설정은 영상 종료 후 관련 영상을 방금 본 영상과 같은 채널로 제한하지만 관련 영상 자체를 없애지는 않는다. 관련 영상 클릭을 앱이 재생 전에 가로채 승인 여부를 검사하는 공식 수단은 확인되지 않았다. 플레이어의 기본 링크나 기능을 가리는 방식은 YouTube 정책상 허용되지 않는다.
- 본인 구독 목록 조회는 해당 가족 구성원의 Google/YouTube 계정 동의가 필요한 기능이다.
- 검색 호출에는 별도 할당량이 있으므로 실제 가족 규모와 검색 빈도를 기준으로 사용량을 확인해야 한다.

## 첫 버전 기본 설계 — 2026-10-09 제안 (변경 가능)

사용자가 따로 정하지 않은 항목에 대한 기본값이다. 이견이 있으면 바꾼다.

- 최초 부모 지정: 배포 설정에 최초 부모의 Google 이메일을 지정해 두고, 그 이메일로 로그인한 계정만 최초 부모가 된다. 처음 로그인한 임의 계정이 부모가 되는 방식은 쓰지 않는다.
- 승인 모드를 껐다 다시 켜면 기존 승인·거절 목록을 그대로 유지한다.
- 같은 아이 프로필이 같은 채널을 대기 중에 다시 요청하면 새 요청을 만들지 않고 기존 요청에 묶는다. 요청 만료는 두지 않는다.
- 부모가 승인을 취소하면 그 채널은 미승인 상태로 돌아가 아이가 다시 요청할 수 있다(거절과 구분).
- 승인 채널 영상 목록은 채널별 업로드 목록(playlistItems, 호출당 1단위)으로 받는다. 채널당 최근 50개를 저장·표시하고(제안) 갱신 주기는 구현 단계에서 정한다. 승인 채널 영상 탭의 검색은 이 저장 목록에서 처리한다(API 미사용).
- 가족 구성원 삭제·권한 변경은 부모만 할 수 있다. 마지막 남은 부모는 자신의 부모 권한을 해제할 수 없다.

## 열린 질문

- 후속 기능으로 YouTube 계정의 기존 구독 목록을 읽을지. 읽는다면 부모 계정부터 연결할지 자녀 계정도 연결할지. 계정 연결 실패나 동의 철회 때 어떤 화면을 보일지. (첫 버전 범위 밖)
- 하루 예상 검색량. `search.list`는 별도 한도로 하루 100회(호출당 1)이며 부모·아이 검색과 더 보기가 함께 쓴다. 실제 사용 후 확인한다.
- 플레이어의 YouTube 이동 링크를 통한 앱·사이트 진입을 가족 기기 설정(Family Link, iOS 스크린 타임 등)으로 보완할지. 서비스 범위 밖의 운영 안내로 다룬다.
- 아이 Google 계정이 Family Link 감독 대상일 때 Supabase Google 로그인이 되는지. 실제 아이 기기로 실증해야 한다.
- 서비스를 아동 대상 API 클라이언트 기준으로 보수적으로 설계할지(쓰기 동작·광고 없음, Made for Kids 조회·추적 비활성). 기본 권고는 보수적 설계다.

## 승인 요청 알림 검토 — 2026-10-09 제안, 미확정

- 공통 기반: 서비스 내 승인 대기함을 원본으로 둔다. 요청 생성 시 아이 프로필·선택 영상·채널·시각·상태를 기록한다. 알림을 놓쳐도 부모가 로그인하면 처리할 수 있고, 승인·거절은 로그인한 서비스 화면에서 수행한다. 같은 아이 프로필과 채널의 중복 요청은 묶는 방향으로 검토한다.
- 무료 운영 추천: 모바일 웹을 홈 화면에 추가하는 PWA와 웹 푸시를 우선 검토한다. 부모가 설치·알림 허용을 해야 하고 iPhone/iPad는 iOS/iPadOS 16.4 이상 홈 화면 웹앱에서 웹 푸시를 지원한다. 네이티브 앱 배포 없이 알림을 받을 수 있다. 기기나 권한 문제로 푸시가 실패해도 승인 대기함은 남는다.
- 이메일 대안: 메일 수신은 설치 없이 가능하지만 발송 수단을 따로 마련해야 한다. Supabase 기본 SMTP는 프로젝트 팀 주소로만 보내며 운영용으로 권장되지 않는다. Resend 무료 요금제는 월 3,000건·일 100건이지만, 가족 계정으로 발송할 도메인 보유·검증 여부를 확인해야 한다. 이메일에는 승인 대기함 링크만 넣고 승인 자체는 로그인 후 처리하는 방향을 권고한다.
- 네이티브 앱 후순위: 푸시를 위해 별도 iOS 앱을 배포하면 Apple Developer Program 연회비가 발생하므로 무료 운영 목표와 맞지 않는다.
- 운영상 제약: Supabase Free 프로젝트는 사용량이 적으면 일시 중지될 수 있다. 가족만 쓰는 서비스에서는 재개 절차와 알림 누락 가능성을 확인해야 한다.

## 개발 전 우선 확인 항목 — 2026-10-09

1. **YouTube 정책 적합성 — 2026-10-09 내부 검토 완료·공식 확인 없음, A안 확정, Compliance Audit 미신청:** 상세는 `docs/01_youtube-policy-review.md`. 미승인 영상을 재생 가능한 것처럼 보여주고 선택 시 재생 대신 승인 요청을 띄우는 현재 흐름은 III.F.3.b(재생 버튼 외 행동 요구 금지) 위반 위험이 높다. 권고안 A: 재생은 승인 채널 영상에만 제공하고, 미승인 결과는 재생 표시 없이 "채널 추가 요청" 카드로 보이며, 제한 이유를 상시 안내(III.C.6·C.7). 대안 B: 검색을 승인 채널 내 검색과 채널 찾기로 분리. 최종 해석은 Compliance Audit으로 확인 가능. 이하 기존 메모: 공식 정책은 재생 버튼 외 추가 행동을 영상 시청 조건으로 요구하는 방식에 제한을 둔다. 부모의 채널 사전 승인 관문이 가족 서비스의 일반 접근 규칙으로 허용되는지 해석이 불명확하다. 플레이어 위에 승인 화면을 덮거나 플레이어 링크를 차단하는 방식은 사용하지 않는다. 필요하면 YouTube API 규정 준수 심사 절차로 설계 설명을 제출해 확인한다. 정책 확인 전 구현 가능하다고 단정하지 않는다.
2. **아동 대상 서비스 판단과 영상 표시:** 서비스가 아동 대상 API 클라이언트에 해당하는지, 그에 따른 Google 통지·개인정보 처리 의무가 있는지 확인한다. 임베드 영상의 Made for Kids 상태를 조회하고, 해당 영상의 추적·데이터 수집 처리를 정책에 맞춘다.
3. **자녀 계정 로그인 실증:** 아이 Google 계정이 Family Link 감독 대상이라면 타사 앱 접근 설정에 따라 로그인이 달라질 수 있다. 실제 아이 기기와 계정으로 Supabase Google 로그인을 시험한다.
4. **검색 사용량:** YouTube Data API의 기본 `search.list` 할당량은 프로젝트당 일 100회다. 검색은 사용자가 입력을 마친 뒤 버튼으로 실행한다. 가족의 예상 검색량과 페이지 넘김 사용량을 계산한다. 승인 채널 영상 목록은 채널의 업로드 목록 조회 방식을 검토한다.
5. **권한과 상태:** 미등록 Google 계정 차단, 부모 권한 확인, 아이 프로필 간 데이터 분리, 승인 취소·중복 요청·알림 실패 상태를 검증한다.
6. **무료 운영 지속성:** Supabase Free의 비활성 일시 중지, 웹 푸시 기기 지원, 이메일 발송 도메인·한도, 영상 재생 불가 예외를 실제 가족 환경에서 시험한다.

## 제약과 검증 근거

- YouTube 검색·재생·계정 데이터는 공식 API 및 플레이어 정책을 따른다. 출시 전 정책과 할당량을 재확인한다.
- 임베드 허용 영상도 권리·지역·정책에 따라 재생되지 않을 수 있으므로 실패 안내가 필요하다.
- 크리에이터 승인 시 앞으로 업로드될 영상도 자동으로 시청 가능해진다. 부모에게 이 범위를 명확히 알리고 승인 취소 수단을 기획한다.
- 기본 재생에는 `rel=0`으로 종료 후 관련 영상을 같은 채널로 좁히는 방향을 검토한다. 승인 단위도 채널로 맞추면 승인된 영상에서 이어지는 같은 채널 영상은 승인 범위에 들어간다. 다만 플레이어 내부 클릭을 사전 검사하거나 YouTube로 이동하는 링크를 막을 수 없으므로 완전한 접근 차단을 약속하지 않는다.
- Supabase Google 로그인은 서비스 이용자 인증이다. 부모/아이 권한과 프로필 접근은 서비스 자체의 등록 정보로 확인하고, 데이터 접근 정책에서 강제해야 한다. Google 로그인만 성공한 미등록 계정은 접근을 거부한다.
- 서비스 Google 로그인과 본인 YouTube 구독 목록을 읽기 위한 Google 동의는 별개다. 후자는 필요한 범위의 추가 권한과 토큰 관리가 필요하다. 부모의 서비스 내부 채널 승인은 YouTube 실제 구독 동작을 발생시키지 않는다.
- YouTube 실제 구독 추가는 계정 변경 API 동작이며, 아동 대상 API 클라이언트에는 YouTube 쓰기 동작 제한이 있다. 이번 범위에서는 실제 구독 자동화를 하지 않는다.
- Google OAuth 동의와 연결 데이터 보관 범위는 최소화하고, 가족별 계정·프로필 혼동을 방지해야 한다.
